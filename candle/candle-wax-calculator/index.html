How It Works

  1. Enter wax fill weight per candle.
  2. Enter the number of candles.
  3. Set the fragrance load recommended for your wax.
  4. Add an optional wax buffer for spills and topping off.

Formula

Base Wax = Fill Weight × Candle Count
Wax to Prepare = Base Wax × (1 + Extra Allowance)
Fragrance Oil = Wax to Prepare × Fragrance Load
