# DayKit V1 Static Site

This package is ready to use as a static-site repository.

## Before launch
1. Replace every `YOUR-DOMAIN.com` occurrence with your real domain.
2. Connect the Contact form to a real form endpoint or email workflow.
3. Review Privacy Policy, Terms, and Disclaimer.
4. Add analytics only after deciding which service you will use.
5. Test every calculator on desktop and mobile.
6. Submit `/sitemap.xml` in Google Search Console after deployment.
