# MakerEstimate Production Build

Production build for https://makerestimate.com/

Upload the CONTENTS of this folder to the root of the existing GitHub Pages repository.

This build removes the GitHub Project Pages <base> path, uses root-relative assets, replaces DayKit with MakerEstimate, and updates canonical/OG/schema/sitemap/robots to makerestimate.com.

- /quilting/quilt-binding-calculator/
- /candle/candle-wax-calculator/
- /candle/candle-fragrance-calculator/
