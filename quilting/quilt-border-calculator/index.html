How the Quilt Border Calculator Works

Each border is calculated in sequence. A border's finished width increases the quilt dimensions before the next border is calculated, so multi-border layouts cannot be estimated accurately by simply multiplying the first border.

Cut Width = Finished Border Width + (2 × Seam Allowance)
New Quilt Width = Current Width + (2 × Finished Border Width)
New Quilt Length = Current Length + (2 × Finished Border Width)

Finished Width vs. Cut Width

The finished border width is what remains visible after sewing. The strip must be cut wider to include seam allowances on both long edges. With a 2-inch finished border and ¼-inch seam allowance, the cut width is 2½ inches.

Single vs. Multiple Quilt Borders

For multiple borders, calculate from the quilt outward. Border 1 changes the quilt size, Border 2 is measured against that larger size, and each later border continues the same process. This calculator handles that sequence automatically for up to four borders.

Butted vs. Mitered Quilt Borders

Butted borders use side strips and top/bottom strips joined with square corners. Mitered borders require additional strip length so adjacent borders can meet diagonally at each corner. The mitered option includes extra length based on border cut width.

How Many WOF Strips Do I Need?

WOF means width of fabric. The calculator estimates the total linear border length, divides it by your usable WOF, and rounds up to whole strips. It then converts strip count × cut width into purchase yardage, rounded up to the nearest ¼ yard or 0.1 meter.

Worked Example: 60 × 80 Inch Quilt

For a 60 × 80-inch quilt with one 2-inch finished border, ¼-inch seam allowances and 42-inch usable fabric, the cut strips are 2½ inches wide. After the border is added, the quilt finishes at approximately 64 × 84 inches before binding.

How to Measure a Quilt Before Adding Borders

Measure through the center of the quilt in the direction needed for each border rather than relying only on the outer edge, which may have stretched. Use the measurements and construction method appropriate to your pattern and quilting workflow.

Frequently Asked Questions

How much fabric do I need for quilt borders?

It depends on quilt size, border width, usable fabric width, corner style and the number of borders. Enter those values above to estimate strips and purchase yardage.

How wide should I cut a 2-inch finished quilt border?

With ¼-inch seam allowances on both long edges, cut the strip 2½ inches wide.

Do I calculate each border separately?

Yes. Each border changes the quilt dimensions. The calculator automatically carries the enlarged dimensions into the next border.

What does WOF mean in quilting?

WOF means width of fabric, typically measured from selvage to selvage. Use the actual usable width after any trimming you expect to do.

Does a mitered border need more fabric?

Usually yes, because each strip needs additional length at the corners to form the diagonal miter.
